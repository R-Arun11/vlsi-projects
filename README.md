# vlsi-projects

A collection of my VLSI design and simulation projects using Verilog and open-source/industry-standard tools.

## 📌 About

This repository contains various digital design and VLSI projects focused on:

- RTL Design using Verilog HDL
- FSM-based digital systems
- Datapath and control unit design
- Functional simulation and verification
- RTL-to-GDSII physical design flow
- ASIC design methodologies

Projects in this repository range from basic digital circuits to complete VLSI implementation flows.

---

## 🛠️ Tools & Technologies

- Verilog HDL
- Vivado
- ModelSim
- OpenROAD
- Yosys
- LibreLane
